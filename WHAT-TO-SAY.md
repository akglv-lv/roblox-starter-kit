# 💬 What to say to Claude

You don't need to know code. Just say what you want **the player to see and do**. Claude asks if it needs more.

## The 7 commands
| Type this | When |
|---|---|
| `/start` | The very first time in a new game |
| `/idea …` | You want something added or changed ⭐ (use this the most) |
| `/fix …` | Something's broken |
| `/test` | "Play my game and tell me what's working" |
| `/ship` | You want to publish an update to Roblox |
| `/teamup` | You're making the game with a friend |
| `/grab` | Your friend made a script in Studio and you want it saved |

You can also just talk normally. "Can you add…" works the same as `/idea`.

## The easy recipe for a good idea
Fill in the blanks (you don't need all of them):

> **/idea** I want **[thing]**.
> Players get it by **[how]**.
> It lets them **[what it does]**.
> It should look like **[looks]**.

### Examples
```
/idea I want pets that follow you. You buy them with coins at an egg on the map. Each pet gives more coins.
```
```
/idea add a sword. clicking swings it and it knocks back other players
```
```
/idea a shop where you can buy speed boosts and jump boosts
```
```
/idea when you join, show a big welcome message with the game name for 3 seconds
```
```
/idea make a lava obby area. touching lava sends you back to the start of that stage
```
```
/idea a daily reward you can claim once a day, it gets bigger if you come back days in a row
```
```
/idea make the upgrades menu look cooler
```

## Fixing things
Say **what you did**, **what you expected**, **what happened**:
```
/fix when I buy the speed upgrade my coins go down but I'm not faster
```
```
/fix the game lags a lot after a few minutes
```
```
/fix on my phone the shop button is too small
```

## Other handy things to ask
- "What should I add next to make people play longer?"
- "Explain how the coins script works, simply."
- "Make the game easier at the start." / "Make upgrades cost more."
- "Undo the last thing you did."
- "Make me a game icon idea." / "Write my game description for Roblox."
- "What does my game need before I publish it?"

## Tips
- **One thing at a time.** Small ideas get built better and faster than giant ones.
- **Test after each one.** Press Play in Studio and try it.
- **Be picky!** "Make it bigger", "the colour is ugly", "slower". Claude doesn't mind changing things.
- Ideas you don't want yet: "put ___ on my ideas list".
